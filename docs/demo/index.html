First Thought

A minimal meditation app built with React Native (Expo). This is a browser demo of the iPhone app. Tap the circle to begin. Tap it again to pause, and once more to resume. While paused, the house takes you home. When the meditation ends, a closing line appears and it returns home on its own. (Here the meditation lasts about 40 seconds instead of 10 minutes, and there is no sound.)
